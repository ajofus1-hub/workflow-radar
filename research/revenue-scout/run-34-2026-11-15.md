### Chess harness interface

The [official chess task](https://make.fun/bounty/tiny-chess-01) confirms the engine does **not** use UCI stdin/stdout and does **not** expose a Python `move(fen)` function. It communicates over HTTP through `MAKEFUN_ENV_URL`. The full indexed rules extract specifies:

- `POST /game {}` — start/get the game in play.
- `POST /move {"game": n, "move": "e2e4"}` — submit a UCI move; house engine replies.
- `POST /resign {"game": n}` — resign the current game.
- Game response includes game/opponent/colour/opening, start_fen, full moves, current fen, plies, last_move, status, legal_moves, result/outcome, next_game, move_limit_ms and max_plies.

Requirements: Python 3.13 standard library, main.py <=4,096 bytes, deterministic, no model calls, 10 sec/move, 1,800 sec/trial, practice Elo >=1,154. The $500 is split across 20 places, first $100. Not pursued because prizes are USDC on Solana only.
